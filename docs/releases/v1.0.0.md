# Release v1.0.0 - Platform Foundation

Release date: 2026-05-27

V1 establishes the foundation of the AWS EKS Platform Golden Path.

The goal of this release is to validate the full baseline path from
application code to AWS infrastructure, container image delivery, Kubernetes
deployment, and cost-aware cleanup.

## Highlights

V1 validates the core platform foundation:

- FastAPI application
- Docker image build
- Amazon ECR repository
- Terraform-managed AWS infrastructure
- Amazon EKS cluster
- Helm deployment
- GitHub Actions CI
- GitHub OIDC foundation
- S3 remote Terraform backend
- cost-aware destroy workflow

## Application foundation

The application is located in:

```text
apps/incident-api
```

It provides baseline operational endpoints:

```text
/health
/ready
/metrics
```

The application is packaged with Docker and runs as a non-root user.

## Infrastructure foundation

Terraform provisions the AWS baseline:

- VPC networking
- public subnets
- internet gateway
- Amazon ECR repository
- Amazon EKS cluster
- managed node group
- IAM roles
- GitHub OIDC provider
- EKS access entries

Terraform state is stored in an S3 remote backend with:

- versioning
- encryption
- public access block
- native lockfile support

## Deployment foundation

V1 validates manual application deployment with Helm.

The baseline deployment flow is:

```text
Terraform apply
-> EKS cluster
-> Docker image push to ECR
-> Helm deployment
-> Kubernetes health validation
-> Terraform destroy
```

## CI foundation

GitHub Actions validates:

- Python tests
- Docker image build
- Helm linting
- Helm rendering
- Terraform formatting
- Terraform validation

GitHub OIDC is introduced as the authentication model for AWS workflows.

## Cost-aware lifecycle

V1 keeps the platform intentionally ephemeral.

Infrastructure is created only for validation and demo sessions, then
destroyed afterwards.

The cleanup path was validated with:

```bash
make tf-destroy
```

## Validation summary

V1 was validated with:

```bash
make app-test
make docker-build
make helm-lint
make helm-template
make tf-validate
make tf-apply
make kubeconfig
make helm-deploy
make tf-destroy
```

## Security impact

V1 establishes the first security baseline:

- no static AWS keys in GitHub
- GitHub OIDC authentication foundation
- non-root application container
- Terraform state stored outside the repository
- ECR image scanning enabled on push
- manual cloud lifecycle to avoid uncontrolled cost

## Out of scope

V1 does not include:

- Prometheus and Grafana observability
- ServiceMonitor discovery
- manual deployment workflow automation
- namespace-scoped GitHub deploy RBAC
- GitHub Environment approval
- NetworkPolicy
- alerting

These are handled in later releases.
